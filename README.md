# Trainees Management System

A Django-based application for managing trainees, departments, and registrations.

## Features
- Trainee management (add, edit, list)
- Excel import for trainees
- Department-based access control
- Registration API

## Setup
1. Install dependencies
2. Run migrations
3. Create superuser
4. Run server
# 1. Remove the incorrectly created git repo inside 'trainers'
rm -Recurse -Force .git

# 2. Move up to the project root folder
cd ..

# 3. Initialize Git in the correct place
git init

# 4. Add all files (including README and .gitignore)
git add .

# 5. Make the first commit
git commit -m "Initial commit"
